# Endpoint Summary

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/products` | Get semua products dengan filter |
| `POST` | `/api/products` | Create product dengan variants |
| `GET` | `/api/products/[id]` | Get product detail |
| `PUT` | `/api/products/[id]` | Update product |
| `DELETE` | `/api/products/[id]` | Delete product |
| `GET` | `/api/products/[id]/variants` | Get semua variants untuk product |
| `POST` | `/api/products/[id]/variants` | Tambah variant ke product |
| `GET` | `/api/variants/[id]` | Get variant detail |
| `PUT` | `/api/variants/[id]` | Update variant |
| `DELETE` | `/api/variants/[id]` | Delete variant |
